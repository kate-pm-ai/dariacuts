Шесть новых страниц dariacuts.com для выкладки

Это дельта-пакет: в нем только шесть новых страниц. Существующие страницы сайта заменять не нужно.

Что в архиве
- Шесть папок страниц, в каждой лежит index.html.
- assets/images/ - только изображения, которые нужны этим шести страницам.

Адреса страниц и файлы
{pages}

Адреса страниц в canonical, og:url, микроразметке и внутренних ссылках указаны со слэшем на конце.
Атрибут noindex удален.

Общие файлы сайта в архив не вложены, потому что уже лежат на dariacuts.com:
- шрифты: /assets/fonts/*.woff2;
- фавиконки: /favicon.ico, /favicon.svg, /favicon-96x96.png, /apple-touch-icon.png;
- изображение для соцсетей: /assets/images/og-cover.webp.

Порядок выкладки
1. Загрузить шесть папок страниц и папку assets/images/ в корень сайта, сохранив структуру путей.
2. Не заменять существующие страницы и общие файлы сайта.
3. Добавить шесть адресов из списка выше в sitemap.xml, если их там еще нет.
4. После выкладки проверить ответы 200, canonical и загрузку изображений на всех шести адресах.
5. Отправить шесть адресов на переобход в Google Search Console.
